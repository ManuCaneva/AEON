# Labels de triaje

Las skills hablan de cinco roles canónicos de triaje. Este archivo mapea esos roles a los labels reales del issue tracker de `ManuCaneva/AEON`.

| Rol en mattpocock/skills | Label en nuestro tracker | Significado                                                    |
| ------------------------ | ------------------------ | -------------------------------------------------------------- |
| `needs-triage`           | `needs-triage`           | El mantenedor tiene que evaluar el issue                       |
| `needs-info`             | `needs-info`             | Esperando más información de quien reportó                     |
| `ready-for-agent`        | `ready-for-agent`        | Especificado por completo, listo para un agente autónomo (AFK) |
| `ready-for-human`        | `ready-for-human`        | Requiere implementación humana                                 |
| `wontfix`                | `wontfix`                | No se va a trabajar                                            |

Cuando una skill mencione un rol (por ejemplo, "aplicá el label de listo para agente"), usá el label correspondiente de esta tabla.

Los cinco labels ya existen en el repo; no hace falta crearlos.
