# Changelog

## 0.6.0 — 2026-10-30

Llegó la mascota flotante de Pomodoro y renovamos la barra lateral para que organices tu estudio con más comodidad.

- **Nuevo** — Sumamos la mascota Pomodoro: un disco flotante siempre visible para seguir tus tiempos mientras estudiás.
- **Arreglado** — En Linux, solucionamos el error que mostraba la ventana completamente gris al iniciar la app.
- **Mejorado** — Renovamos el diseño de la barra lateral con un estilo visual más suave y despejado.
- **Mejorado** — Agregamos confirmación antes de eliminar elementos en la barra lateral para evitar accidentes.

## 0.5.1 — 2026-10-27

- **Arreglado** — Se corrigió la publicación del instalador y las actualizaciones para Windows.

## 0.5.0 — 2026-10-27

Esta versión trae mejoras importantes al Pomodoro y al calendario, además de otras novedades.

- **Nuevo** — Consultá la agenda completa del mes directamente desde el calendario.
- **Nuevo** — Enterate de las novedades de cada versión directamente desde la app.
- **Mejorado** — Mejoramos el Pomodoro: es más preciso, redimensionable y recuerda tu tamaño preferido.
- **Mejorado** — El calendario mensual se adapta mejor a tu pantalla para una mejor visualización.
- **Mejorado** — Reordená tus objetivos fácilmente con las nuevas flechas de dirección.
